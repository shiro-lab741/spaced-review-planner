# Spaced Review Planner

A small study-support tool for spaced repetition and daily review planning.

## Purpose

This project helps learners generate review dates from a start date.

The goal is to reduce missed reviews and make daily study planning easier.

## How it works

The tool uses a simple review interval pattern:

- Day 1
- Day 3
- Day 6
- Day 11
- Day 18

A learner can enter a start date and generate future review dates.

## Features

- Generate review dates from a selected start date
- Use a simple spaced repetition schedule
- Run directly in a browser
- Keep the project lightweight and easy to understand
